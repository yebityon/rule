# llm-config

Claude Code と Codex のグローバル指示を 1 ファイルで管理する。

## 構成

`shared/AGENTS.md` が両エージェント共通の指示である。編集対象はこのファイルのみで、各エージェントは以下のシンボリックリンク経由でこのファイルを直接読み込む。編集内容は、次に起動したセッションから反映される。

| エージェント | 読み込まれるパス |
| --- | --- |
| Claude Code | `~/.claude/CLAUDE.md` → `shared/AGENTS.md` |
| Codex | `~/.codex/AGENTS.md` → `shared/AGENTS.md` |

共通ファイルをリポジトリ直下ではなく `shared/` に置いている。リポジトリ直下に `AGENTS.md` があると、このリポジトリで Codex を起動した際にプロジェクト指示としても読み込まれ、同じ内容が二重に入るためである。

## 初回セットアップ

```sh
./setup.sh
```

- 上記 2 か所に `shared/AGENTS.md` へのシンボリックリンクを作成する
- 既存ファイルがある場合は、警告を表示して置き換えるかを確認する。置き換える場合、バックアップは作成しない
- 既に正しいリンクになっている場合は何もしない
- リンクは絶対パスで作成するため、リポジトリを移動した場合は再実行する

## 対象外

以下はエージェントごとに形式が異なるため、本リポジトリでは管理していない。

- Claude Code: `~/.claude/settings.json`（権限、モデル、環境変数）
- Codex: `~/.codex/config.toml`（モデル、MCP サーバー）、`~/.codex/rules/*.rules`（コマンド許可ルール）
